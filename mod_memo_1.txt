# 📋 ウクレレ・アレンジ学習＆リアルタイムセッションWebアプリ 機能追加仕様書（完全版）

## 1. 開発背景と目的
現行アプリは「仮想パートナーの演奏に対し、TAB譜なしで帯域・空き場所を意識して即興演奏する」という実践（アウトプット）に特化している。
しかし、アドリブやアレンジの「語彙（型・パターン）」を持たない初心者・学習者にとってはハードルが高く、暗闇で手探りするような負担が生じている。

本改修では、**「メロディ自動生成」および「既存のMIDI→TAB変換機能」を最大限に活かし、**
1. **アレンジ・フレーズの型を学ぶ「インプット（学習）機能」**
2. **セッション時に手元を迷わせない「視覚的リアルタイム・ガイド機能」**
を追加することで、インプットからアウトプットへスムーズに移行できる段階的学習システムを構築する。

---

## 2. システムの入力ソース（前提条件）
本アプリは以下の2系統の音源・データ入力ソースを持ち、追加する新機能は**両方のソースに対して共通で動作する設計**とする。

*   **入力A（メロディ自動生成）:** MIDIファイルなしで、キーやコード進行に応じたメロディ/コードデータをアプリ内部で動的生成する（手軽な練習・実験用）。
*   **入力B（MIDIインポート）:** ユーザーが読み込んだ外部MIDIファイルを解析し、既存の「MIDI → TAB変換エンジン」でウクレレTAB譜に起こす（実在の曲用）。

## 3. 全体学習フロー（UXコンセプト）

```text
[ステップ1: インプット（型・アレンジ学習モジュール）]
 ・自動生成またはMIDIの曲に対し、コード着せ替え/奏法適用/メロディフェイクを実験。
 ・アレンジ結果は既存の「MIDI→TAB変換機能」でリアルタイムにTAB譜化・音源再生。
       ↓
[ステップ2: アシスト付きアウトプット（ガイド付きセッション）]
 ・仮想パートナーとセッション。自分のウクレレ指板UIに「光るコードトーン」を表示。
 ・画面端に選択式のお手本フレーズ（短尺TAB）を提示。
       ↓
[ステップ3: 完全即興アウトプット（現行の耳セッション）]
 ・ガイドやTAB譜を非表示にし、耳と帯域マップのみで空き場所を狙う即興演奏。

```

## 4. 追加・拡張機能の仕様詳細

### 機能①：アレンジ・リハーモナイズ学習モジュール（インプット機能）

* **概要:** 規定のメロディやコード進行（自動生成 / MIDI）に対して、様々なアレンジパターンを適用・試聴・視覚化する機能。
* **詳細機能:**
1. **コード着せ替え（リハーモナイズ）:** メロディに対して「王道」「ジャジー」「哀愁系」等のコードパターンを置換適用。
2. **奏法テンプレート適用:** コード音を「8ビートストローク」「アルペジオ」「ジャカソロ風」などのMIDI音符列に展開。
3. **メロディ・フェイク:** 原曲メロディに対し、シンコペーション（リズムずらし）や経過音（アプローチノート）を動的挿入。


* **連携要件:** アレンジ適用後のデータは、既存の「MIDI → TAB変換エンジン」を通過させて画面にTAB譜描画する。

### 機能②：リアルタイム・指板ガイド（視覚的アシスト機能）

* **概要:** セッション中、画面上のウクレレ指板UIに「今弾けば絶対に外れない音（コードトーン/スケール音）」をリアルタイムで点灯させる。
* **処理ロジック:**
1. 現在演奏中のコード（自動生成またはMIDIデータ）の構成音を取得。
2. ウクレレの各弦（0〜15フレット）でのピッチ配置を動的計算。
3. 指板UI上にルート音（赤）、3度/5度（緑）などのコードトーンをリアルタイム描画。
4. 設定による「High-G / Low-G」の指板割り当て切替に対応。



### 機能③：選択式おすすめフレーズ（ナビゲーション）

* **概要:** セッション中、「何を弾けばいいかわからない」を回避するため、コード進行に合った短尺フレーズ（TAB譜カード）を2〜3種類画面端に提示。
* **UI/UX:** ユーザーは提示されたフレーズを真似して弾くか、指板ガイドを見て自由に弾くかを選択できる。

### 機能④：難易度（アシストレベル）選択

* **ビギナー:** 指板ガイド（光るコードトーン）表示 ＋ おすすめフレーズ表示
* **ノーマル:** 指板ガイド（光るコードトーン）表示のみ
* **ハード（現行仕様）:** ガイドなし（帯域マップと耳のみでセッション）

### 3. 追加・拡張機能の仕様詳細

#### 機能①：アレンジ・リハーモナイズ学習モジュール（インプット機能）

* **概要:** 規定のメロディやコード進行に対して、様々なアレンジパターンを実験・試聴できる機能。
* **詳細機能:**
1. **コード着せ替え（リハーモナイズ）:** メロディに対して「王道」「ジャジー」「哀愁系」等のコードパターンを適用。
2. **奏法テンプレート適用:** 指定コード進行を「8ビートストローク」「アルペジオ」「ジャカソロ風」などの音符パターン（MIDIデータ）に展開。
3. **メロディ・フェイク:** 原曲メロディのMIDIに対し、シンコペーションや経過音（アプローチノート）を追加。


* **技術仕様要件:** 既存の「MIDI → TAB変換エンジン」をデータ表示の出力部として再利用する。

#### 機能②：リアルタイム・指板ガイド（視覚的アシスト）

* **概要:** セッション中、ウクレレの指板UI上で「今鳴らせば絶対に外れない音（コードトーン/スケール音）」をリアルタイムでハイライト表示する。
* **処理ロジック:**
1. パートナー演奏の現在小節/拍のコード情報（MIDIデータ）を取得。
2. ウクレレの各弦・フレット（0〜15フレット）における対応ピッチをリアルタイム計算。
3. ルート音（赤）、3度/5度（緑）などのコードトーンを画面上のウクレレ指板UIに点灯。
4. High-G / Low-G 設定に応じた運指位置の動的切替。



#### 機能③：選択式おすすめフレーズ（アシスト付きセッション）

* **概要:** アドリブセッション中、「何を弾けばいいか分からない」を防ぐため、カード形式で短尺フレーズ（TAB譜・音）を画面端に提示。
* **UI/UX:**
* 現在進行中のコードに適合するフレーズ（アルペジオパターン、オブリガートなど）を2〜3種類提案。
* ユーザーは「提示されたフレーズを弾く」か「ガイド指板を見て自由に弾く」かを選択可能。



#### 機能④：難易度（アシストレベル）選択

* **ビギナー:** 指板ガイド（光るコードトーン）表示 ＋ おすすめフレーズ提示
* **ノーマル:** 指板ガイド（光るコードトーン）表示のみ
* **ハード（現行仕様）:** ガイドなし（帯域マップと耳のみでセッション）

---

### 4. 既存コードベース（MIDI → TAB変換）の活用方針

* **MIDIデータの統一利用:** アンプラグドな音データではなく、アプリ内部のすべての音楽状態（パートナーの演奏、ユーザーのお手本フレーズ）をMIDI形式で一元管理する。
* **変換エンジンの呼び出し:** 動的に変更・生成されたMIDIデータを既存の「MIDI → TAB変換関数」に渡し、リアルタイムで画面上のTAB譜描画を行う。

全体像の評価と優位性
1. 「MIDIなしのメロディ自動生成」がもたらす最大の強み
「曲を用意する手間」の完全排除:
ユーザーが外部からMIDIファイルを探して用意しなくても、アプリを開いて「キー」「雰囲気（ジャズ風、ポップス風など）」を選ぶだけで、すぐにアレンジ学習やセッションを始められます。

「型（パターン）」の無限生成:
あらかじめ固定された曲だけでなく、自動生成されたメロディに対して「コードを着せ替える」「アルペジオを適用する」練習ができるため、教材としての賞味期限（リプレイ性）が無制限になります。

2. 「MIDIインポート」との役割分担が明確化
自動生成メロディ: 日常的な「短時間の型トレ・アレンジ実験・即興トレーニング」用。

MIDIインポート: 「自分の好きな実在の曲」でアレンジやセッションを試す本番用。
