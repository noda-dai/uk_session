仮想パートナーに合わせて、自分だけの「間」を即興で弾く練習

🎯 このアプリでできること
仮想パートナー（AIが自動演奏）が先に弾き始め、あなたはその音を聴きながら 被らない音域・タイミングを即興で弾きます。 タブ譜は出しません。「耳で聴いて空き場所を見つける感覚」を鍛えます。
  1. 楽器・キー・コード進行を選ぶ（またはMIDIファイルを読み込む）
  2. 役割を決める — あなたがメロディを弾くのか、コードを弾くのかを選択する。パートナーは残りの役割を担当します
  3. セッション開始 — パートナーが演奏を始めます。タブ譜と帯域マップを見て「パートナーが使っていない音域」を確認する
  4. 自分の楽器で合わせる — 帯域マップの緑エリアを狙って演奏。パートナーの音とぶつからないよう「引き算」の感覚で弾く
  5. ヒントを参考に — 画面下のヒントが「A弦ハイフレットのチャンス！」などリアルタイムで案内します
💡 MIDIインポートの場合: 好きな曲のMIDIファイルを読み込むと、その曲をパートナーが弾きます。あなたはその上でアドリブを乗せる練習ができます。
📖 音楽用語の解説
コンピング（CHORD_COMP）
コード（和音）を分散させたり刻んだりして伴奏する演奏スタイル。メロディの邪魔をしないよう音数を絞るのがポイント。
例：メロディが休んでいる拍に短くコードを入れる
オブリガード（OBBLIGATO）
主旋律と一緒に鳴る「合いの手」的なフレーズ。メロディの隙間を飾る即興的な装飾音。「必須の（obligatory）」という意味の音楽用語。
例：ボーカルが息継ぎする瞬間に短いフレーズを挿し込む
引き算の演奏
音を足すのではなく「弾かない音・休む場所」を意識する演奏の考え方。2人で演奏するとき、同じ音域を同時に埋めると音がぶつかる。相手が弾いている場所を避けることで全体のサウンドがすっきりする。
周波数帯域マップ
パートナーが使っている音の高さ（MIDI音高）を色で表した図。オレンジ色はパートナーが占有している帯域、緑色はあなたが弾けるスペース。縦軸が音の高さ（上ほど高音）、横軸が時間（左から右へ進む）。
バトンタッチモード
数小節ごとにメロディ担当とコード担当を交互に切り替えるモード。役割が変わった瞬間に演奏スタイルをすぐ切り替える「俊敏さ」を鍛える。
例：4小節はあなたがメロディ → 次の4小節はパートナーがメロディ
High-G / Low-G チューニング
ウクレレの4弦（G弦）の音程の違い。High-Gは高いG音で、Low-Gは低いG音。Low-Gにすると低音域が広がりベースラインも弾けるようになる。
演奏複雑度（シンプル / 標準 / 高密度）
あなたがどのくらい音を弾くかの宣言。「シンプル」を選ぶとパートナーが厚い伴奏を弾いてくれる。「高密度」を選ぶとパートナーはガイドトーン（3度・7度）だけに絞り、あなたの音と重ならないよう引いてくれる。

🎸 指板ガイド（コードトーン）
今のコードで「弾けば外れない音」が光ります。色の意味はTAB譜と共通です： 緑=ルート　 青=安定音　 紫=色彩音　 橙=テンション
💡 おすすめフレーズ（お手本）
弾き方に迷ったら、この中から1つ選んで真似してみましょう。もちろん無視して自由に弾いてもOKです。
🎼 パートナーのタブ譜
パートナーが弾いているフレット位置を示します。あなたの譜面はあえて表示しません — 帯域マップとヒントを手がかりに、自分で「空き場所」を見つけて弾いてください。
